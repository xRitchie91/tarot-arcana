🔮 Tarot Arcana
An immersive, interactive tarot reading experience built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.
Designed as a portfolio-grade frontend project focused on animation, UI storytelling, and API-driven interactions.

📸 Preview

🧠 About the Project
Tarot Arcana is a modern web application that simulates a mystical tarot reading experience. Users enter a question, draw three cards, and receive an AI-generated interpretation of their situation.
The goal of this project is to demonstrate:
Advanced frontend UI design
Smooth motion design and animations
API integration with dynamic state handling
Strong visual storytelling
Production-ready React/Next.js structure

⚙️ Tech Stack
Next.js (App Router)
TypeScript
Tailwind CSS
Framer Motion
REST API (custom /api/reading)

🎴 Features
🔮 Interactive tarot card drawing system
✨ Animated 3-card flip reveal sequence
🌌 Dynamic starfield background animation
💬 AI-style interpretation output
🎨 Glassmorphism + cosmic UI design
⚡ Loading states with animated messaging
📱 Responsive mobile-first layout

🧩 How It Works
User enters a question
App sends request to /api/reading
Server returns:
3 tarot cards
Interpretation text
Cards animate into view with flip transitions
Interpretation is revealed after animation completes

🚀 Getting Started
1. Clone the repo
git clone https://github.com/xRitchie91/tarot-arcana.git
cd tarot-arcana
2. Install dependencies
npm install
3. Run development server
npm run dev
4. Open in browser
http://localhost:3000
